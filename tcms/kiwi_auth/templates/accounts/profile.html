Cara Mendapatkan Token Monday

  1. Buka akun Monday.com Anda.
  2. Klik Avatar Profil di pojok kiri bawah.
  3. Pilih menu Developers (atau Admin > API).
  4. Buka tab Developer > My Access Tokens.
  5. Klik Show atau Generate, salin token tersebut, lalu tempel di kolom Personal API Token.
  6. Klik tombol Test Koneksi untuk memverifikasi token sebelum menyimpan.
